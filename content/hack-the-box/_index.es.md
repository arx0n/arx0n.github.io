# Hack The Box

Mi recorrido por **Hack The Box**, documentando las máquinas que voy completando y todo lo que voy aprendiendo durante el proceso.

Aquí recopilo mis **writeups**, desde la enumeración inicial hasta el acceso y la escalada de privilegios.

> Enumerar. Explotar. Aprender.

## Máquinas

En esta sección iré añadiendo las máquinas que vaya completando.

Cada writeup recoge el proceso seguido, las técnicas utilizadas, los errores encontrados y los conocimientos que me llevo de cada máquina.

## Qué encontrarás

-  Reconocimiento y enumeración
-  Enumeración web
-  Linux
-  Windows
-  Acceso inicial
-  Escalada de privilegios
-  Técnicas y herramientas utilizadas
-  Lecciones aprendidas

## Mi objetivo

No se trata solamente de conseguir una flag.

Quiero entender **por qué funciona cada técnica**, aprender de los problemas que aparecen durante el proceso y dejar documentado el camino para poder volver a consultarlo en el futuro.
